# 视频播放接口对接文档

## 📋 文档概述

本文档描述了如何对接视频在线播放功能，支持流式传输、防快进保护等特性。

**基础URL**: `http://your-domain/api/download`

**版本**: v1.0

**更新日期**: 2026-01-29

---

## 🎯 功能特性

- ✅ 流式传输视频，支持边下边播
- ✅ 播放密钥验证，防止未授权访问
- ✅ 时效性控制（密钥有效期24小时）
- ✅ 前端防快进保护（仅允许正常播放和快退）
- ✅ 视频下载支持（独立密钥）
- ✅ 多种视频格式支持（MP4、AVI、MOV、WMV、FLV、WEBM、MKV）

## 📌 接口列表

### 1. 获取视频播放页面

#### 接口说明
跳转到视频播放页面，前端无需自己实现播放器，直接使用后端提供的播放页面即可。

#### 请求方式
```
GET /api/download/player?playKey={playKey}
```

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| playKey | String | 是 | Base64编码的播放密钥，由后端生成 |

#### 返回结果
返回HTML播放页面，包含完整的防快进逻辑。

#### 使用示例
```javascript
// 前端跳转到播放页面
function playVideo(playKey) {
    window.location.href = `/api/download/player?playKey=${playKey}`;
}

// 或在新窗口打开
function playVideoInNewWindow(playKey) {
    window.open(`/api/download/player?playKey=${playKey}`, '_blank');
}
```

### 2. 获取视频流（直接对接）

#### 接口说明
获取视频流数据，前端需要自己实现video元素和防快进逻辑。

#### 请求方式
```
GET /api/download/play/{playKey}
```

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| playKey | String | 是 | Base64编码的播放密钥 |

#### 请求头
无特殊要求

#### 返回结果

**成功响应**:
```
状态码: 200 OK
Content-Type: video/mp4 (或其他视频格式)
Accept-Ranges: none
Cache-Control: no-cache, no-store, must-revalidate
X-Content-Type-Options: nosniff

响应体: 视频二进制流
```

**失败响应**:
```
状态码: 404 Not Found
Content-Type: text/plain;charset=UTF-8

响应体: 视频文件不存在
```

#### 使用示例
```javascript
// 方式1: 直接使用video标签
<video id="videoPlayer" controls>
    <source :src="`/api/download/play/${playKey}`" type="video/mp4">
</video>

// 方式2: Vue/React 示例
// Vue 3
<template>
    <video
        ref="videoPlayer"
        :src="videoUrl"
        controls
        @timeupdate="handleTimeUpdate"
        @seeking="handleSeeking"
    ></video>
</template>

<script setup>
import { ref, computed } from 'vue';

const props = defineProps({
    playKey: String
});

const videoPlayer = ref(null);
const lastTime = ref(0);
const ALLOWED_DRIFT = 2; // 允许2秒误差

const videoUrl = computed(() => `/api/download/play/${props.playKey}`);

// 防快进逻辑
function handleTimeUpdate() {
    const video = videoPlayer.value;
    const currentTime = video.currentTime;

    // 检测快进
    if (currentTime > lastTime.value + ALLOWED_DRIFT) {
        video.currentTime = lastTime.value;
        console.warn('禁止快进');
    } else {
        lastTime.value = currentTime;
    }
}

// 防拖拽快进
function handleSeeking() {
    const video = videoPlayer.value;
    if (video.currentTime > lastTime.value + ALLOWED_DRIFT) {
        video.currentTime = lastTime.value;
        console.warn('禁止拖拽快进');
    }
}
</script>
```

### 3. 下载视频

#### 接口说明
下载视频文件到本地，用于保存或离线观看。

#### 请求方式
```
GET /api/download/video/{key}
```

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| key | String | 是 | Base64编码的下载密钥 |

#### 返回结果

**成功响应**:
```
状态码: 200 OK
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="video.mp4"
Content-Length: 12345678

响应体: 视频二进制流
```

#### 使用示例
```javascript
// 直接下载
function downloadVideo(key) {
    window.location.href = `/api/download/video/${key}`;
}

// 或使用隐藏的iframe下载
function downloadVideoWithIframe(key) {
    const iframe = document.createElement('iframe');
    iframe.style.display = 'none';
    iframe.src = `/api/download/video/${key}`;
    document.body.appendChild(iframe);

    // 下载完成后移除iframe
    setTimeout(() => {
        document.body.removeChild(iframe);
    }, 5000);
}
```

## 🔐 密钥获取流程

### 步骤1: 后端生成播放密钥

前端需要先从后端其他接口获取播放密钥。通常在以下场景中生成：

#### 场景1: 学生提交作业后查看参考视频
```javascript
// 前端调用作业提交接口
async function submitHomework(homeworkId, file) {
    const formData = new FormData();
    formData.append('file', file);

    const response = await fetch(`/api/homework/${homeworkId}/submit`, {
        method: 'POST',
        body: formData
    });

    const result = await response.json();

    // 后端返回播放密钥和下载密钥
    return {
        playKey: result.data.playKey,      // 用于在线播放
        downloadKey: result.data.downloadKey // 用于下载视频
    };
}
```

#### 场景2: 课程视频播放
```javascript
// 前端调用课程详情接口
async function getCourseDetail(courseId) {
    const response = await fetch(`/api/course/${courseId}`);
    const result = await response.json();

    // 返回课程信息，包含视频的播放密钥
    return {
        courseName: result.data.name,
        playKey: result.data.videoPlayKey
    };
}
```

### 步骤2: 使用密钥播放视频

```javascript
// 获取到playKey后，跳转到播放页面
async function playCourseVideo(courseId) {
    try {
        const course = await getCourseDetail(courseId);
        window.location.href = `/api/download/player?playKey=${course.playKey}`;
    } catch (error) {
        console.error('获取课程信息失败', error);
        alert('加载视频失败');
    }
}
```

### 方案B: 前端自己实现播放器（需要开发）

如果需要自定义UI或集成到现有播放器，参考以下实现：

#### 核心代码
```javascript
class SecureVideoPlayer {
    constructor(videoElement) {
        this.video = videoElement;
        this.lastTime = 0;
        this.ALLOWED_DRIFT = 2; // 允许2秒误差
        this.init();
    }

    init() {
        // 监听时间更新
        this.video.addEventListener('timeupdate', () => {
            const currentTime = this.video.currentTime;

            // 检测快进
            if (currentTime > this.lastTime + this.ALLOWED_DRIFT) {
                this.video.currentTime = this.lastTime;
                this.showToast('不支持快进');
                return;
            }

            this.lastTime = currentTime;
        });

        // 监听拖拽
        this.video.addEventListener('seeking', () => {
            if (this.video.currentTime > this.lastTime + this.ALLOWED_DRIFT) {
                this.video.currentTime = this.lastTime;
                this.showToast('不支持拖拽快进');
            }
        });

        // 允许快退
        this.video.addEventListener('seeking', () => {
            if (this.video.currentTime < this.lastTime) {
                this.lastTime = this.video.currentTime;
            }
        });

        // 锁定播放速率
        Object.defineProperty(this.video, 'playbackRate', {
            get: () => 1.0,
            set: () => 1.0
        });

        // 移动端触摸事件
        this.initTouchEvents();
    }

    initTouchEvents() {
        // 禁止双击快进
        let lastTap = 0;
        this.video.addEventListener('touchstart', (e) => {
            const currentTime = new Date().getTime();
            if (currentTime - lastTap < 300) {
                e.preventDefault();
                this.showToast('不支持快进');
            }
            lastTap = currentTime;
        });

        // 禁止右键菜单
        this.video.addEventListener('contextmenu', (e) => {
            e.preventDefault();
            return false;
        });
    }

    showToast(message) {
        // 实现提示逻辑
        console.log(message);
        // 或者使用 UI 库的 toast 组件
    }
}

// 使用示例
const video = document.getElementById('videoPlayer');
const player = new SecureVideoPlayer(video);
```

#### React Hook 示例
```javascript
import { useRef, useEffect } from 'react';

function useSecureVideo(playKey) {
    const videoRef = useRef(null);
    const lastTimeRef = useRef(0);
    const ALLOWED_DRIFT = 2;

    useEffect(() => {
        const video = videoRef.current;
        if (!video) return;

        const handleTimeUpdate = () => {
            if (video.currentTime > lastTimeRef.current + ALLOWED_DRIFT) {
                video.currentTime = lastTimeRef.current;
                toast.warning('不支持快进');
                return;
            }
            lastTimeRef.current = video.currentTime;
        };

        const handleSeeking = () => {
            if (video.currentTime > lastTimeRef.current + ALLOWED_DRIFT) {
                video.currentTime = lastTimeRef.current;
                toast.warning('不支持拖拽快进');
            }
        };

        video.addEventListener('timeupdate', handleTimeUpdate);
        video.addEventListener('seeking', handleSeeking);

        return () => {
            video.removeEventListener('timeupdate', handleTimeUpdate);
            video.removeEventListener('seeking', handleSeeking);
        };
    }, [playKey]);

    return videoRef;
}

// 组件使用
function VideoPlayer({ playKey }) {
    const videoRef = useSecureVideo(playKey);

    return (
        <video
            ref={videoRef}
            src={`/api/download/play/${playKey}`}
            controls
            playsinline
            webkit-playsinline
        />
    );
}
```

## ⚠️ 重要注意事项

### 1. 密钥安全性
- ⚠️ 播放密钥和下载密钥是不同的，不能混用
- ⚠️ 密钥有时效性（默认24小时），过期后需要重新获取
- ⚠️ 密钥包含用户信息，不要泄露给他人

### 2. 播放限制
- ⚠️ 防快进功能主要针对移动端用户
- ⚠️ 电脑端用户可能通过开发者工具绕过限制
- ⚠️ 不能防止录屏和下载

### 3. 性能优化
- 💡 使用流式传输，边下边播，无需等待下载完成
- 💡 建议视频文件使用MP4格式（H.264编码），兼容性最好
- 💡 大文件建议使用HLS分片，提升加载速度

### 4. 兼容性
- ✅ 支持所有现代浏览器
- ✅ 支持iOS Safari、Android Chrome
- ⚠️ IE浏览器不支持（需要升级到Edge）

## 🐛 常见问题

### Q1: 播放时提示"视频文件不存在"
**原因**:
- 播放密钥无效或已过期
- 视频文件已被删除

**解决**:
- 重新获取播放密钥
- 检查视频文件是否存在

---

### Q2: 播放时可以快进
**原因**:
- 前端未实现防快进逻辑
- 使用了原生video标签未添加事件监听

**解决**:
- 使用后端提供的播放页面（推荐）
- 或参考文档实现防快进逻辑

---

### Q3: 移动端视频全屏后无法播放
**原因**:
- iOS需要添加 `playsinline` 属性

**解决**:
```html
<video playsinline webkit-playsinline>
```

---

### Q4: 视频加载很慢
**原因**:
- 视频文件太大
- 网络带宽不足

**解决**:
- 压缩视频文件
- 使用HLS分片传输
- 提供多个清晰度选项
