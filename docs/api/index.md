# SignLab API 接口文档

## 概述

SignLab 是一个基于 Spring Boot 3.5 的实验室管理系统，提供实验管理、学生管理、教师管理、成绩管理等功能。

### 基础信息

- **服务地址**: `http://175.178.76.145:8085`
- **API 基础路径**: `/api`
- **认证方式**: JWT Bearer Token
- **响应格式**: JSON

### 认证说明

除了公开接口外，所有接口都需要在请求头中携带 JWT Token：

```
Authorization: Bearer <token>
```

### 通用响应格式

所有接口返回统一的响应格式：

```typescript
interface ApiResponse<T> {
  code: number;        // 状态码，200 表示成功
  message: string;     // 响应消息
  data: T;            // 响应数据
}
```

### 角色权限说明

系统支持三种角色，权限层级递增：

- **STUDENT (学生)**: 等级 1
- **TEACHER (教师)**: 等级 2
- **ADMIN (管理员)**: 等级 3

高等级角色拥有低等级角色的所有权限。

## 常见问题

### 1. 如何获取 Token？

调用登录接口 `/api/auth/login` 或 `/api/auth/login-by-code`，成功后会返回 Token。

### 2. 如何使用 Token？

在后续请求的 Header 中添加：
```
Authorization: Bearer <your_token>
```

### 3. 密码规则是什么？

- 首次登录密码格式：`syjx@学号后四位`
- 自定义密码必须是 6 位数字
- 管理员可重置密码为初始格式

### 4. 实验步骤类型说明

- `type=1`: 观看视频步骤
- `type=2`: 数据收集步骤
- `type=3`: 题库答题步骤
- `type=4`: 提交实验报告步骤

### 5. 签到状态说明

- `NORMAL`: 正常签到（班级学生）
- `CROSS_CLASS`: 跨班签到
