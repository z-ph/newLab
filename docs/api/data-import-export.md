# 数据导入/导出

## 基础路径

- 导入：`/api/test/excel`
- 导出：`/api/teacher/export`

---

## 数据导入

### 1. 批量导入用户（Excel）

**接口地址**: `POST /api/test/excel/import/users`

**权限要求**: ADMIN

**请求参数**:
```
file: MultipartFile  // Excel 文件（.xls 或 .xlsx）
```

**Excel 格式要求**:

| 列名 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 用户名 | 学号/工号 | 是 | 2021001 |
| 姓名 | 学生/教师姓名 | 是 | 张三 |
| 角色 | 学生/教师 | 是 | 学生 |
| 院系 | 所属院系 | 否 | 计算机学院 |
| 专业 | 所属专业 | 否 | 计算机科学与技术 |

**响应示例**:
```json
{
  "code": 200,
  "message": "导入完成！成功���95条，重复：3条，失败：2条，耗时：1500ms",
  "data": "导入完成！成功：95条，重复：3条，失败：2条，耗时：1500ms\n错误详情：\n第5行：用户名为空\n第10行：角色格式错误"
}
```

**说明**:
- 重复用户会自动跳过
- 格式错误的行会记录错误信息
- 返回导入成功、重复、失败的详细统计

---

### 2. 获取用户导入模板

**接口地址**: `GET /api/test/excel/template/users`

**权限要求**: ADMIN

**响应**: Excel 文件下载

**文件名**: `用户导入模板.xlsx`

**说明**: 下载包含示例数据的 Excel 模板，按照模板格式填写后可批量导入

## 数据导出

### 1. 导出课程成绩

**接口地址**: `GET /api/teacher/export/course-grades/{courseId}`

**权限要求**: TEACHER

**路径参数**:
- `courseId`: 课程 ID

**请求参数**:
```
semester: string (可选)  // 学期，例如：2024-2025-1
```

**响应**: Excel 文件下载

**文件名**: `课程成绩_COURSE001.xlsx`

**Excel 格式**:

| 列名 | 说明 |
|------|------|
| 课程ID | 课程编号 |
| 课程名称 | 课程名称 |
| 学号 | 学生学号 |
| 姓名 | 学生姓名 |
| 成绩 | 成绩（字符串） |
| 数字成绩 | 成绩（数字） |
| 成绩类型 | 期末/期中/平时等 |
| 学期 | 学期 |
| 教师评语 | 教师评语 |
| 审核状态 | 已审核/未审核 |
| 审核人 | 审核人 |
| 审核时间 | 审核时间 |

**示例请求**:
```
GET /api/teacher/export/course-grades/COURSE001?semester=2024-2025-1
```

---

### 2. 导出考勤记录

**接口地址**: `GET /api/teacher/export/attendance-records/{courseId}`

**权限要求**: TEACHER

**路径参数**:
- `courseId`: 课程 ID

**请求参数**:
```
startDate: string (可选)  // 开始日期，例如：2025-01-01
endDate: string (可选)    // 结束日期，例如：2025-01-31
```

**响应**: Excel 文件下载

**文件名**: `考勤记录_COURSE001.xlsx`

**Excel 格式**:

| 列名 | 说明 |
|------|------|
| 课程ID | 课程编号 |
| 实验ID | 实验编号 |
| 学号 | 学生学号 |
| 姓名 | 学生姓名 |
| 班级代码 | 班级代码 |
| 签到状态 | NORMAL / CROSS_CLASS |
| 签到时间 | 签到时间 |
| IP地址 | 签到IP地址 |

**示例请求**:
```
GET /api/teacher/export/attendance-records/COURSE001?startDate=2025-01-01&endDate=2025-01-31
```

## 使用指南

### 批量导入用户流程

1. **下载模板**
   ```
   GET /api/test/excel/template/users
   ```

2. **填写数据**
   - 打开下载的 Excel 模板
   - 按照格式填写用户信息
   - 确保必填字段不为空
   - 保存文件

3. **导入数据**
   ```
   POST /api/test/excel/import/users
   Content-Type: multipart/form-data
   ```
   - 选择填写好的 Excel 文件
   - 上传并等待导入完成
   - 查看导入结果

4. **处理结果**
   - 查看成功、重复、失败的数量
   - 根据错误信息修正数据
   - 重新导入失败的记录

---

### 导出成绩流程

1. **确定导出范围**
   - 指定课程 ID
   - 可选：指定学期

2. **发起导出请求**
   ```
   GET /api/teacher/export/course-grades/COURSE001?semester=2024-2025-1
   ```

3. **下载文件**
   - 浏览器会自动下载 Excel 文件
   - 文件名为 `课程成绩_COURSE001.xlsx`

4. **查看数据**
   - 打开 Excel 文件
   - 查看导出的成绩数据
   - 可进行进一步分析或打印

---

### 导出考勤记录流程

1. **确定导出范围**
   - 指定课程 ID
   - 可选：指定日期范围

2. **发起导出请求**
   ```
   GET /api/teacher/export/attendance-records/COURSE001?startDate=2025-01-01&endDate=2025-01-31
   ```

3. **下载文件**
   - 浏览器会自动下载 Excel 文件
   - 文件名为 `考勤记录_COURSE001.xlsx`

4. **查看数据**
   - 打开 Excel 文件
   - 查看导出的考勤数据
   - 可进行统计分析

## 文件大小限制

- **导入文件**: 最大 10MB
- **导出文件**: 无限制（取决于数据量）

---

## Excel 格式要求

### 支持的格式

- `.xls` (Excel 97-2003)
- `.xlsx` (Excel 2007+)

### 编码要求

- **推荐**: UTF-8 编码
- **支持**: GBK 编码（中文环境）

### 数据格式

- **日期**: `yyyy-MM-dd` 或 `yyyy/MM/dd`
- **数字**: 使用数字格式，不要用文本
- **文本**: 不要包含特殊字符（如换行符、制表符等）

---

## 常见问题

### 1. 导入失败怎么办？

- 检查 Excel 格式是否正确
- 查看错误消息，定位问题行
- 确保必填字段不为空
- 确认数据格式正确

### 2. 导出的文件打不开怎么办？

- 确保使用支持 `.xlsx` 格式的软件（如 Excel 2007+、WPS）
- 检查文件是否损坏（重新下载）
- 检查磁盘空间是否充足

### 3. 导出的数据不完整？

- 检查是否有权限访问所有数据
- 确认查询条件是否正确
- 联系管理员检查数据完整性

### 4. 导入时提示"文件格式错误"？

- 确认文件后缀是 `.xls` 或 `.xlsx`
- 尝试用 Excel 重新保存文件
- 不要直接修改文件后缀名

### 5. 如何处理大批量数据导入？

- 分批导入，每次不超过 1000 条
- 先导入少量数据测试
- 查看导入结果，确认无误后再导入全部数据

## 错误处理

### 常见错误码

| 错误码 | 说明 | 解决方法 |
|--------|------|----------|
| 400 | 文件格式错误 | 检查文件格式 |
| 400 | 文件为空 | 确认文件有数据 |
| 500 | 导入失败 | 查看错误详情，修正数据 |
| 500 | 导出失败 | 联系管理员 |

### 错误响应示例

```json
{
  "code": 500,
  "message": "导入失败: 第5行用户名已存在"
}
```

---

## 最佳实践

1. **导入前备份**
   - 导入前先备份现有数据
   - 避免数据丢失

2. **测试导入**
   - 先导入少量数据测试
   - 确认无误后再批量导入

3. **数据验证**
   - 导入前验证数据格式
   - 检查必填字段是否完整

4. **分批处理**
   - 大批量数据分批导入
   - 每批不超过 1000 条

5. **定期导出**
   - 定期导出重要数据
   - 做好数据备份
